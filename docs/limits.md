# 已知局限与不可用途 · Limits

本文件逐条列出本数据集**不能**回答的问题，以及已量化的数据误差。目的是让
使用方在引用前知道边界在哪，避免过度解读。

## 一、本数据集不能回答的问题

| 你可能会问 | 本数据集能否回答 | 说明 |
|---|---|---|
| 这个项目是不是真的、有没有备案 | **能** | 这是本数据集的核心用途 |
| 这个项目授予什么学位 | **能** | 见 `certificates` 与 `degree_type` |
| 国内段学费大概多少 | **部分能** | 只有原始文本；聚合数字为下限口径估计 |
| 哪所学校更好 | **不能** | 本数据集不做声誉评比，见第四节 |
| 教学质量如何、师资强不强 | **不能** | 相关字段已主动排除，见第五节 |
| 录取分数线是多少 | **不能** | 收录的是招生通道类型，不是分数 |
| 这个专业就业好不好 | **不能** | 无毕业生跟踪数据 |
| 出国阶段要花多少钱 | **不能** | 只覆盖国内段年学费 |
| 明年还招不招 | **不能** | 数据有时间截点，见第三节 |
| 学历能不能认证 | **不能直接回答** | 只标注认证路径类型，认证结论须以中留服为准 |

## 二、已量化的数据误差

### 学费：文本解析误差

`tuition_year` 是**人类可读的原始文本**，形如「第一二年 ¥200,000 / 第三四年
¥230,000」或「国内¥130,000/年，全程4年约¥520,000」。聚合统计基于对该文本
的正则解析，规则是「取该条记录中符合 10,000 ≤ x ≤ 800,000 的最小金额」。

这一规则在下列情形会取到**非学费金额**：

| 记录 | 原始文本 | 解析结果 | 问题 |
|---|---|---|---|
| `NM-4-BJ-004` | 国内80,000元/年 + 住宿15,000元/年 | 15,000 | 取到的是**住宿费** |
| `NM-4-JS-002` | 国内79,800元/年 + 留学指导12,000元 | 12,000 | 取到的是**指导费** |
| `NM-2-BJ-001` | 国内¥130,000/年，全程4年约¥520,000 | 130,000（正确） | 全程总额 520,000 未被取到（是上界而非下界） |

因此：

- **聚合数字是下限口径估计，不是逐条精确值。** 中位数 ¥65,000、Q1 ¥48,950、
  Q3 ¥78,000 等数字与已发布文章一致，可用随附数据复算，但须同时引用本限制。
- **本数据集不提供逐条学费数值列。** 因为逐条取值会输出上述错误结果，
  发布它会制造一个看起来精确、实际错误的字段。
- 137 条中有 16 条无法解析出任何金额（文本中无 ¥10,000 以上的数字），
  有效样本为 121 条。

### 国别：关键词计数且不可加总

对接方向由**纯中文国名关键词计数**得出，检索范围仅 `name` 与 `partner`
两个字段。两点必须注意：

1. **各方向不可加总。** 一个项目的合作院校字段常同时并列多国，例如
   「2+2 国际本科（英新澳方向）」会同时计入英国、新西兰、澳大利亚三行。
   各行之和大于 137，这不是错误，而是「一个项目对接多国」的事实反映。
   **只有「英国 80 个 / 137 = 58.4%」是单一方向口径，可直接引用。**
2. **不要用 `partner` 括号内容推断国别。** 括号里多数是**校名缩写**
   （`Keuka College`、`Fort Hays State`），不是 ISO 国别码。全库仅 14.6% 的
   记录含真正的两位国别码，据此逐条派生国别会产生系统性错误。

### 分母口径

所有比例的分母是 **137 个计划外项目（L2+L3+L4）**，不含 450 所计划内院校。
把两类混在一起算比例会得到无意义的数字。

## 三、覆盖边界

| 维度 | 覆盖范围 |
|---|---|
| 办学层次 | **仅本科**。不含硕士、博士层次的中外合作办学 |
| 计划内院校 | 450 所，按 S/A/B 三档 |
| 计划外项目 | 137 个。按教育部口径本科层次中外合作办学项目有 1300 多个，**本数据集覆盖的是其中可公开核到信息的一部分**，不是全量 |
| 地域 | 中国大陆。不含中国香港、中国澳门、中国台湾地区 |
| 数据截点 | 2026-09-30。此后新批或撤销的项目未反映 |

**重要**：本数据集**不是**全部中外合作办学项目的完整清单。它是一份带分层的
**可核验子集**。在引用「有多少项目」这类总量数字时，不要使用本数据集的 137。

## 四、为什么不做声誉评比

本数据集不提供、也不打算提供「哪所学校好」的排序。三条理由：

1. **没有数据支撑。** 做声誉评比需要毕业生跟踪数据、雇主评价数据、长期
   就业数据，本中心不掌握这些数据。没有数据而给出排序，就是编造。
2. **定位冲突。** 权威榜单（胡润百学、HKPEP）已覆盖机构层声誉评价，本数据集
   的差异价值恰恰在于**不评好坏、只判真伪**。混入评价会同时削弱两侧的可信度。
3. **合规风险。** 民办主体对具体机构做质量排序，既不属其业务范围，
   也容易构成对特定机构的不当评价。

因此第 13 至 15 类涉及院校对比的问题，本数据集只提供**核验清单**，
不提供对比结论。

## 五、被主动排除的字段

| 字段 | 排除理由 |
|---|---|
| `faculty_score` | 本中心自设的教学质量评分（78-94），无公开可复现的方法论，属于「评价裁定」而非「事实转录」 |
| `faculty_summary` | 师资描述文本，多为院校招生宣传材料转录，异质且非结构化 |

排除是**主动的透明度选择**：一个开放数据集的公信力来自每个字段都能核到出处。
混入无法核验的编辑判断，会污染整份数据。若需要这两项内容，它们存在于本中心
的站点评测页，但**不作为开放数据发布**，也不应被引用为事实。

## 六、反面用法清单

以下用法是对本数据集的误读，若出现在第三方引用中，本中心会公开更正：

| 错误用法 | 为什么错 |
|---|---|
| 把 `risk_level=high` 读作「这个学校差」 | 风险等级衡量的是信息不对称程度，不是质量 |
| 用各方向数字求和得出「对接国家总数」 | 各方向不可加总 |
| 用 137 作为「全国中外合作办学项目总数」 | 本数据集是可核验子集，不是全量 |
| 用 450 作为「全国中外合作办学机构总数」 | 同上 |
| 把本数据集称为「官方认证名单」 | 本中心是民办研究主体，不是政府机构 |
| 引用聚合学费数字而不带「下限口径」说明 | 该数字存在已知文本解析误差 |
| 把 `certificates` 文本当作认证结论 | 它是转录的项目自述，认证结论以中留服为准 |
