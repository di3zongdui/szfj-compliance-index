# 方法论 · Methodology

本文件说明数据是怎么产生的，以及每条判定依据什么规则。目的是让第三方能够
判断本数据集**是否可信**，而不是仅凭署名相信它。

## 一、定位与边界

本中心是**民办研究主体**，不具备行政授权资质。因此本数据集在定位上做了三项
主动收缩：

1. **不碰「评估」与「认证」。** 这两项在国内已有行政授权主体（学位与研究生
   教育发展中心、中国教育国际交流协会、上海市教育评估院等），民办主体介入
   既无依据也无必要。
2. **不做「哪所好」的声誉评比。** 权威榜单（胡润百学、HKPEP）只评机构且不含
   项目；本数据集不与之竞争，只回答不同的问题——**哪个是真的**。
3. **不宣称「行业标准」。** 全国性行业组织的法定业务已覆盖标准研究与第三方
   评价，本中心仅做**事实转录 + 分层索引**，法律性质是信息整理，不是评价裁定。

由此得出一个可校验的界线：**本数据集中的每一个字段，要么能从公开渠道核到
出处（`transcribed`），要么能由公开规则推出（`classified`），要么是纯机械
计算（`derived`）。** 凡是属于「我们自己的判断」且无公开方法论的字段，一律
不发布（见第五节）。

## 二、四层合规分级（`level` 字段）

分层的唯一依据是**招生录取通道与可核验的备案状态**，与办学质量无关。

| 层级 | 判定条件 | 证据要求 |
|---|---|---|
| **L1** 计划内（统招） | 纳入国家普通高校招生计划，通过高考志愿或官方综合评价通道录取 | 教育部涉外监管信息网可查（crs.jsj.edu.cn）；学信网可查学籍；毕业获中方学历学位证书 |
| **L2** MOE 备案计划外 | 经教育部备案，但走自主招生、不占高考志愿 | 教育部涉外监管信息网可查备案；获外方学位 + 中留服认证 |
| **L3** 中留服项目 | 中留服（教育部留学服务中心）体系下的国际本科 / SQA 3+1 项目，自主招生 | 中留服项目名单可查；学位需逐校核实认证路径 |
| **L4** 校际自主跨境 | 校际自主合作项目，无 MOE 备案、不属中留服体系 | 公开渠道信息有限，须逐项核实 |

**判定优先级**：可核到备案编号的，按备案类型归层；核不到备案但属中留服名单
的，归 L3；两者都不满足的，归 L4。这形成一条单向的「证据递减」链条，因此
层级数字可以直接读作**可核验证据的强度**，而不是质量高低。

L1 内部另设 S/A/B 三档：S 档仅收录**独立法人**中外合作大学；非法人中外合作
机构归入 A / B 档。当前分布为 S 档 14 所、A 档 131 所、B 档 305 所。

## 三、风险等级判定（`risk_level` 字段）

风险等级的默认映射由层级决定：

| 层级 | 默认风险 | 含义 |
|---|---|---|
| L1 | `none` | 统招通道，学籍与学历证书路径明确 |
| L2 | `low` | 有备案，但无中方学位证，考公考编部分岗位可能受限 |
| L3 | `medium` | 学位需逐个核实中留服认证路径；对接院校可能不在认证名单内 |
| L4 | `high` | 无备案、不属中留服体系，认证路径不确定 |

**必须说明的一点**：风险等级衡量的是**家长事前难以察觉的信息不对称程度**，
**不是项目质量**。一个 L4 项目完全可能教学扎实，它的高风险来自「公开渠道
信息有限、需要家长自行核实的事项多」，而非「这个项目不好」。任何把
`risk_level` 当作学校好坏评分的用法都是对本数据集的误读。

**逐条覆盖**：默认映射允许被单条记录覆盖。当前版本共 1 条例外：

- `NM-4-GD-004` 广东金融学院中外联合培养 2+2/3+1 国际项目 — 该项目同时存在
  **统招获双学位**与**计划外仅获外方学位**两条通道，风险特征无法单一归类，
  故下调为 `medium`，并在 `risk_notes` 中说明「需区分」。
  这是全库唯一一条层级与风险不对应的记录。

剩余 136 个计划外项目的风险等级与层级一一对应。使用方可用
`level` 与 `risk_level` 两个字段自行复算这条规则。

## 四、字段的三种来源

| 来源标记 | 数量 | 说明 | 举例 |
|---|---|---|---|
| `transcribed` | 15 | 直接转录自公开渠道的事实 | `name`、`partner`、`tuition_year`、`certificates`、`sources` |
| `classified` | 3 | 按本文件公开规则判定的分类 | `level`、`risk_level`、`program_type` |
| `derived` | 2 | 由其他字段机械推导 | `mode_family`、`degree_type` |

逐字段的来源标注见 [`codebook.md`](codebook.md)。

**派生字段的可复现性**：两个派生字段的解析函数与内部核验脚本
（用于校验对外发布稿件数字的 64 项断言脚本）**逐字共用同一份实现**，因此
数据集中的分布与已发布文章中的数字必然一致。这是刻意设计——历史上有过
因临时另写解析逻辑，导致学费中位数偏差 3,000 元、最小值偏差 6,000 元的
事故，此后确立「口径只允许有一处实现」的规则。

## 五、为什么有些字段不发布

| 字段 | 类型 | 不发布理由 |
|---|---|---|
| `faculty_score` | 本中心自设教学质量评分（78-94，仅 11 条有值） | 属「评价裁定」，无公开可复现的方法论，且与「不做声誉评比」的定位直接冲突 |
| `faculty_summary` | 师资描述文本（137 条） | 多为院校招生宣传材料的转录，异质、非结构化，发布易被误读为本中心结论 |
| 逐条学费数值列 | 数值 | 学费文本常并列住宿费、留学指导费、全程总额，实测按文本取值会产生错误结果（见 [`limits.md`](limits.md)） |
| 逐条国别列 | 分类 | `partner` 括号内多为校名缩写（如 `Keuka College`、`Fort Hays State`）而非国别码，仅 14.6% 含国别码，无法逐条可靠派生 |

排除是**主动选择而非隐瞒**：一个开放数据集的公信力来自字段可被逐个核到出处。
混入无法核验的编辑判断，会污染整份数据。

## 六、采集与核验流程

1. **采集**：从教育部涉外监管信息网、中留服项目名单、各校招生简章等公开渠道
   逐条采集，并在每条记录的 `sources` 字段标明该条来源。
2. **归类**：按第二节规则归入 L1-L4，按第三节规则标注风险等级。
3. **核验**：由脚本对全库做一致性断言，包括记录数、标识唯一性、字段集完整性、
   风险规则对应关系，以及**与对外发布稿件的数字交叉核对**（20 项）。
4. **构建**：`scripts/build_open_dataset.py` 从源数据生成全部发布格式，
   并产出 `MANIFEST.sha256`。任何一次发布都可从源数据完整重建。
5. **更正**：外部指正优先受理。经核实的更正计入补丁版本并在
   [`../CHANGELOG.md`](../CHANGELOG.md) 留痕。

## 七、可复现性

本仓库中的数据文件全部由构建脚本生成，不存在手工编辑的内容。

更重要的是：**任何人都可以独立复算全部聚合数字，而不需要任何私有数据。**

```bash
git clone https://github.com/di3zongdui/szfj-compliance-index.git
cd szfj-compliance-index
python scripts/verify_dataset.py
```

该脚本从已发布字段出发，重新执行下列全部计算，并与已发布的 `facets` 文件
逐项比对：

1. 风险分布、学位结构、培养模式分布、对接方向计数、地域分布；
2. 学费分位数（Q1/Q3 用 `statistics.quantiles(n=4)`，P10/P90 用简单索引）；
3. 两个派生字段 `mode_family` 与 `degree_type` —— 输入仅取 `mode`、
   `certificates`、`risk_notes` 三个已发布字段；
4. 三种格式（JSON / CSV / JSONL）是否逐字段一致；
5. `MANIFEST.sha256` 是否匹配；
6. 对外发布稿件中的 13 个数字是否与数据集一致。

任一项失败即退出码 1。这意味着**本数据集的核心统计数字可以被第三方独立复现
和证伪**——这是开放数据集与「一份看起来很专业的表格」之间的实质区别。

## 八、已知局限

本文件只说明方法。方法本身的边界与不可用途，逐条列在
[`limits.md`](limits.md)，引用前请一并阅读。
